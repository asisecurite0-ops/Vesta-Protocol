# Vesta Protocol 🛡️✨

**Vesta Protocol** est une application décentralisée (dApp) d'épargne rotative (tontines automatisées) et de rendement sécurisée, construite sur le **Polygon Mainnet**. 

Elle permet de mettre en commun des capitaux au sein de cercles cryptographiques autonomes, avec une transparence totale et une exécution garantie par des contrats intelligents.

---

## 🚀 Fonctionnalités Clés

* **Cercles d'Épargne Rotative :** Déployez ou rejoignez des cercles de tontine automatisés pour épargner et faire tourner les cotisations en toute confiance.
* **GuaranteePool :** Un mécanisme de collatéralisation indépendant garantissant l'éligibilité et la sécurité des participants.
* **YieldVault :** Optimisation du rendement des fonds verrouillés.
* **Gouvernance DAO :** Participation des utilisateurs à l'évolution et à la gestion du protocole.

---

## 🛠️ Stack Technique

* **Framework :** [Next.js](https://nextjs.org/) (App Router, React)
* **Styling :** Tailwind CSS
* **Blockchain :** Polygon Mainnet / Smart Contracts Solidity

📦 Installation et Lancement en Local
Cloner le dépôt :

Bash
git clone [https://github.com/vestaprotocol/vestaprotocol.git](https://github.com/vestaprotocol/vestaprotocol.git)
cd vestaprotocol/frontend
Installer les dépendances :

Bash
npm install
Lancer le serveur de développement :

Bash
npm run dev
Ouvrez http://localhost:3000 dans votre navigateur pour voir l'application.
